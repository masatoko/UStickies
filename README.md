# UStickies

UStickiesは、UnityのScene上に付箋形式のメモを配置・管理するためのEditor拡張パッケージ。

## 動作環境

- Unity 6000.3
- Unity 6000.6 (動作確認済み)
- Unity Editor専用

## インストール

UnityのPackage Managerで `Install package from git URL...` を選択し、次のURLを入力する。

```text
https://github.com/masatoko/UStickies.git?path=/Packages/com.tenkaigames.ustickies#v0.1.2
```

機能、操作方法、データの保存方法については[パッケージREADME](Packages/com.tenkaigames.ustickies/README.md)を参照。
