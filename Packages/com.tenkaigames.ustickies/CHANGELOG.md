# Changelog

## [0.2.0] - 2026-09-24

### Added

- Scene Viewの内容カードへカテゴリ色またはプロジェクト共通色の半透明背景を追加
- 内容カードの最大幅、最大高さ、文字色、背景色、不透明度、文字サイズ設定を追加

### Changed

- 内容カードを本文サイズに合わせて伸縮し、最大幅で折り返すよう変更
- UStickiesの表示設定とカテゴリ設定を`Project Settings > UStickies`へ統合
- 背景色、不透明度、文字サイズをプロジェクト共有設定として保存

## [0.1.2] - 2026-09-21

### Changed

- 開発プロジェクトをUnity 6000.6へ更新
- Unity 6000.3および6000.6向けの推奨バージョンを`v0.1.2`へ更新

## [0.1.1] - 2026-09-21

### Changed

- Unity 6000.3と6000.6の対応状況をREADMEに明記
- Scene識別子を`SceneHandle`で保持し、Unity 6000.6に対応

## [0.1.0] - 2026-09-21

### Added

- Scene Viewへの付箋形式のノート表示
- 位置固定ノートとGameObjectに紐づくノート
- ノートの検索、絞り込み、並べ替え、完了状態の管理
- プロジェクト共通カテゴリの管理
- Unity Undoによる操作の取り消し
