# UStickies UX決定事項

## この文書について

初期バージョンにおけるUStickiesのインターフェースと操作方法をまとめる。

`docs/spec.md` と記述が競合する場合、この文書で明示したUX上の決定を初期バージョンでは優先する。正式な仕様へ統合するときは、両文書の記述を一致させる。

## ノートの内容

- ノートにタイトルは持たせない。
- 本文はプレーンテキストとし、Rich TextやMarkdownには対応しない。
- 本文が空のノートも保存できる。
- 本文が空の場合、一覧には「空のノート」と表示する。
- 初期バージョンでは表示位置オフセットを持たせない。
- 一覧では以下を表示する。
  - 本文の先頭行
  - カテゴリ
  - 完了状態

## Scene Viewからの新規作成

### 位置固定ノート

- Scene Viewの右クリックメニューに `UStickies > Add Note` を表示する。
- 右クリック位置からSceneへレイを飛ばす。
- Colliderにヒットした場合、ヒット位置へ作成する。
- Colliderにヒットしなかった場合、右クリック位置とScene Viewのpivotが同じ奥行きになる位置へ作成する。
- 作成直後にScene View上で小型編集ポップアップを開く。
- 新規作成ポップアップには本文とカテゴリを表示する。
- 初期カテゴリは `Note` とする。

### GameObject紐づけノート

- Scene Viewの右クリックメニューに `UStickies > Add Note to Selected GameObject` を表示する。
- HierarchyのGameObject右クリックメニューに `UStickies > Add Note` を表示する。
- 複数のGameObjectが選択されている場合、アクティブなGameObjectだけを紐づけ対象にする。
- 作成直後の表示位置は対象GameObjectのTransform位置とする。
- 初期バージョンでは表示位置オフセットを設けないため、対象GameObjectのTransform位置へ常に追従する。

## 編集ポップアップ

### 表示項目

既存ノートの編集ポップアップには以下を表示する。

- 本文
- カテゴリ
- 完了状態
- 常時表示
- GameObjectの紐づけ先

ユーザー向けの完了状態は `Done` / `Undone`、常時表示は `Pin` / `Unpin` と表記する。
編集ポップアップのチェックボックスは `Done` と `Pin` とする。

位置固定ノートのワールド座標や内部IDなど、内部管理用の値は表示しない。

### 確定とキャンセル

- `Save` ボタンで変更を確定する。
- `Cancel` ボタンで変更を破棄する。
- `Ctrl+Enter` で変更を確定する。
- `Escape` で変更を破棄する。
- ポップアップ外のクリックでは閉じない。
- 新規作成中にキャンセルした場合、作成したノート自体を削除する。

## GameObjectの紐づけ変更

- 位置固定ノートをGameObjectへ紐づけると、対象GameObjectのTransform位置へ移動する。
- GameObjectとの紐づけを解除すると、その時点のTransform位置をワールド座標として保持する。
- 紐づけ先GameObjectが削除された場合、最後のTransform位置を保持して位置固定ノートへ切り替える。
- 紐づけ先削除による切り替え時には一度だけ通知を表示する。
- 通知後は通常の位置固定ノートとして扱い、恒久的な警告表示は行わない。

## Scene View上の選択と編集

- ノートアイコンのシングルクリックでノートを選択する。
- ノートアイコンのダブルクリックで編集ポップアップを開く。
- 選択中ノートの再クリックでは選択を解除しない。
- ノート以外の場所をクリックすると選択を解除する。
- `Escape` で選択を解除する。
- 編集ポップアップが開いている場合、`Escape` はポップアップのキャンセルを優先する。
- ノート選択はUnityのGameObject選択と独立して管理し、現在のGameObject選択を変更しない。

## Scene View上の移動

- 位置固定ノートは `Shift + 左ドラッグ` で移動できる。
- 通常のドラッグでは移動しない。
- GameObject紐づけノートは初期バージョンではドラッグ移動できない。
- ノート移動はUnity Undoに対応する。

## Scene View上のアイコン

- アイコンはカメラ距離にかかわらず、画面上で常に同じ大きさとする。
- カテゴリ色をアイコンへ反映する。
- 通常ノートと完了済みノートには、それぞれ専用アイコンを使用する。
- 未選択の通常ノートは半透明、未選択の完了済みノートはさらに薄く表示する。
- 選択中アイコンは不透明にする。
- オブジェクトに遮蔽されているアイコンは、半透明にして手前へ表示する。
- 複数アイコンが同じ画面位置で重なっても、自動整列やスタック化を行わない。
- 選択中アイコンは最前面へ表示する。

## Scene View上の内容カード

- 選択中ノートの本文全文を読み取り専用で表示する。
- Scene View上にはカテゴリ名と完了状態の文字を表示せず、カテゴリはアイコン色で示す。
- 常時表示がONのノートは、非選択時にも内容カードを表示する。
- 内容はアイコンの右側へ固定して表示する。
- Scene View外へはみ出す場合も位置を補正しない。
- プロジェクト設定でカスタム背景色が無効の場合はカテゴリ色、有効の場合はプロジェクト共通色の背景を表示する。
- 背景の不透明度は背景色と独立したプロジェクト共通設定とし、初期値は0.35とする。
- 文字サイズはUnity標準値を初期状態とし、プロジェクト設定で8pxから48pxの範囲へ変更できる。
- 枠線、カテゴリ色の帯、アイコンとの接続線は表示しない。
- 複数の内容表示が重なっても、自動配置しない。
- 選択中ノートのカードは最前面へ表示する。
- カードは本文に合わせて伸縮し、ユーザー設定の最大横幅で折り返す。
- ユーザー設定の最大縦幅を超える長文は、カード内スクロールで全文を表示する。
- 文字色はUnity標準色を初期状態とし、ユーザー設定で任意の色へ変更できる。

## ノート表示全体の切り替え

- Scene ViewのオーバーレイとScene Notes Windowの両方に、ノート表示全体のON/OFFを用意する。
- 表示ON/OFFはすべてのSceneに共通で適用する。
- 状態はユーザーごとのローカル設定として保持する。

## Notes Window

### 開き方と基本構成

- Unity上部メニューの `Window > UStickies > Notes` から開く。
- Unityへドッキング可能な独立したEditorWindowとする。
- ウィンドウはノート一覧を中心とし、常設の編集ペインは設けない。
- 上部ツールバーに `Add New Note` を配置する。
- 編集にはScene Viewと共通の編集ポップアップを使用する。

### 一覧の選択

- シングルクリックでノートを選択する。
- ダブルクリックで編集ポップアップを開く。
- 選択した行を縦に展開し、本文全文を読み取り専用で表示する。
- 長文の場合、展開行の本文部分をスクロール可能にする。
- Notes WindowとScene Viewの選択状態は常に同期する。
- Windowから選択しただけではScene Viewのカメラを移動しない。

### 一覧からの操作

選択中の展開行には以下の操作を表示する。

- ノート位置へ移動
- 編集
- 削除
- 完了状態の切り替え
- 常時表示の切り替え

同じ操作を行の右クリックメニューにも表示する。

- 削除時に確認ダイアログは表示しない。
- 削除はUnity Undoで復元できる。
- 削除前に選択していたノートをUndoで復元した場合、そのノートを再選択する。

### キーボード操作

- 上下キーで一覧の選択を移動する。
- `Enter` で選択中ノートの編集ポップアップを開く。
- `Delete` で選択中ノートを削除する。

### ノート位置への移動

- `移動`を実行すると、ノート位置をScene Viewのpivotに設定する。
- Scene Viewのカメラ方向は維持する。
- ノートを確認しやすい距離までズームする。

### Add New Note

- Windowで選択中のSceneへ位置固定ノートを作成する。
- 作成座標にはアクティブなScene Viewのpivotを使用する。
- 作成先SceneとScene Viewが表示中のSceneが異なる場合も、Windowで選択中のSceneを作成先として優先する。
- 作成直後に新規ノートを選択し、編集ポップアップを開く。

## 検索とフィルタ

### 文字列検索

- 検索対象は本文とする。
- 大文字と小文字を区別しない部分一致検索とする。
- 入力をスペースで分割し、複数語がすべて含まれるノートだけを表示するAND検索とする。

### カテゴリフィルタ

- 複数カテゴリを同時に選択できる。
- 選択したいずれかのカテゴリに一致するノートを表示するOR条件とする。
- `すべて` と `選択解除` の操作を用意する。

### 完了状態フィルタ

以下の3状態から選択する。

- すべて
- 未完了のみ
- 完了済みのみ

初回起動時の既定値は `すべて` とする。それ以後は前回の選択を復元する。

### Scene Viewへの適用

- 検索、カテゴリフィルタ、完了状態フィルタに `Scene Viewにも適用` の切り替えを設ける。
- 初回起動時はOFFとする。
- それ以後は前回の状態を復元する。

## 一覧の並び順

以下から選択できるようにする。

1. 作成日時が新しい順
2. 作成日時が古い順
3. Scene内での登録順
4. カテゴリ順

- 初回の既定値は `作成日時が新しい順` とする。
- 完了状態は並び順へ影響させない。
- 選択した並び順はユーザーごとの設定として保持する。

## 複数Sceneの扱い

- Notes Windowに、現在開いているSceneを選択するドロップダウンを表示する。
- ユーザーが選択したSceneを維持し、UnityのアクティブScene変更には自動追従しない。
- 選択中Sceneが閉じられた場合だけ、UnityのアクティブSceneへ切り替える。

## UStickies Project Settings

### 開き方

- `Edit > Project Settings > UStickies` から開く。
- ユーザーごとの内容カード表示設定と、プロジェクト共有のカテゴリ設定を同じ画面にまとめる。
- 内容カード表示設定はProject Settings画面から操作するが、保存先は `UserSettings` とする。
- 内容カードの背景色と不透明度はプロジェクト共有設定として保存する。
- 内容カードの文字サイズはプロジェクト共有設定として保存する。

### 編集操作

- カテゴリの追加、削除、名称変更、色変更ができる。
- ドラッグ＆ドロップでカテゴリの表示順を変更できる。
- 初期カテゴリ `Note`、`Todo`、`Bug` は名称と色を変更できる。
- 初期カテゴリは削除できない。
- カテゴリIDは名称や色を変更しても維持する。
- 使用中カテゴリを削除するときは、参照中ノートの置き換え先カテゴリを選んでから削除する。
- 未使用カテゴリは置き換え先の指定なしで削除できる。

## ユーザーごとに保持する設定

以下はSceneやチーム共有データへ保存せず、ユーザーごとのプロジェクト設定として保持する。

- 検索文字列
- 選択中のカテゴリフィルタ
- 完了状態フィルタ
- `Scene Viewにも適用` の状態
- 一覧の並び順
- ノート表示全体のON/OFF
- Scene View上の内容カードの最大横幅、最大縦幅、文字色

## UIデザイン

- Notes Window、UStickies Project Settings、編集WindowはUI Toolkitで構築する。
- Window UIはUSSでフラットデザインを適用する。
- UnityのLightテーマとDarkテーマへ追従する。
- Scene View上のワールド座標を扱う表示と操作にはIMGUIとHandlesを使用する。
- Scene View上のカードもWindowと整合するフラットな外観にする。
